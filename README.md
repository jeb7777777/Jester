## Overview

Simple and effective chess engine.

- Can be used as a template for custom-made chess bot.
- simplified searching algorithm but provide strong result.
- Made with dedication.

## Features

- [x] Implemented Negamax with alpha-beta prunging.
- [x] Implemented Quiescence Search
- [ ] Planned pondering
- [ ] Planned common optimization quirk


## Getting Started

This is a standalone engine and not come with a GUI to play.

To play with the engine, use a premade GUI like https://cutechess.com/ and https://encroissant.org/
